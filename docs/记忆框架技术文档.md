## 1. 架构概览

## 2. 核心组件

### 2.1 MemoryType 枚举

5 种记忆类型：

```python
from memory import MemoryType

MemoryType.FACT        # 事实: "我叫小明"、"我1990年生"
MemoryType.PREFERENCE  # 偏好: "我喜欢苹果"、"讨厌香菜"
MemoryType.EVENT       # 事件: "昨天去公园"、"今天买了新电脑"
MemoryType.CONTEXT     # 上下文: "最近在学PyTorch"、"刚看完这部剧"
MemoryType.SKILL       # 技能: "我会Python"、"会弹吉他"

# 使用
MemoryType.FACT           # "fact"
MemoryType.get_display_name(MemoryType.FACT)  # "事实"
```

```python
from memory import MemoryItem, MemoryType

item = MemoryItem(

#   "updated_at": 1725192821.0,

```

### 2.3 MemoryStore 向量存储

ChromaDB 封装层：

```python
from memory import MemoryStore

store = MemoryStore(
    storage_path="data/memory",
    model_path="./models/bge-small-zh-v1.5"
)

# 初始化
store.initialize()

# 添加
store.add([MemoryItem(content="用户叫小明", memory_type=MemoryType.FACT)])

# 智能添加（自动替换）
store.smart_add([MemoryItem(content="用户叫小红", memory_type=MemoryType.FACT)])

# 检索
results = store.search(query="我叫什么", n_results=5, min_score=0.3)

# 删除
store.delete(["memory_id_1", "memory_id_2"])

# 获取全部
all_mem = store.get_all()

# 清空
store.clear()
```

### 2.4 MemoryManager 管理器

单例模式，对外的统一入口：

```python

manager = get_memory_manager()

manager.clear_all()
```

## 3. 与 Agent 的集成方式

记忆系统有 3 种与 Agent 的交互方式：

### 3.1 被动注入（MessageBuilder）

**时机**：每次对话开始时

**代码位置**：`agent/chat/message_builder.py`

```python
# 在构建 System Prompt 时自动检索 1 条最相关的记忆
memory_text = await asyncio.to_thread(
    self.memory_manager.get_relevant_memories,
    query=user_input, max_items=1
)
if memory_text:
    parts.append(f"【你对用户的记忆】\n{memory_text}")
```

**效果**：LLM 直接在 System Prompt 中看到记忆，无需额外调用。

**示例**：
```
用户输入: "好饿啊"
检索 query: "好饿啊"
命中记忆: "用户爱吃香蕉"

System Prompt 注入:
【你对用户的记忆】
- [preference] (置信度 85%) 用户爱吃香蕉

LLM 回复: "饿了呀？那要不要吃点香蕉补充能量呀？"
```

**特点**：
- 零额外 LLM 调用
- 只检索 1 条最相关的（max_items=1）
- 更多相关的由 LLM 主动调用 query_memory 工具获取

### 3.2 主动查询（LLM 工具）

**时机**：LLM 判断需要更多记忆时

**工具列表**（`tools/tool_memory.py`）：

| 工具 | 描述 | 示例 |
|------|------|------|
| query_memory | 查询记忆 | `query_memory(query="我叫什么")` |
| add_memory | 添加记忆 | `add_memory(content="用户叫小明", memory_type="fact")` |
| update_memory | 更新记忆 | `update_memory(id="...", content="用户叫小红")` |

**调用流程**：
```
用户: "我之前说过我喜欢什么吗"
    ↓
MessageBuilder 被动注入: 1 条记忆（可能不够）
    ↓
LLM 第 1 次调用: 判断需要更多 → 调用 query_memory
    ↓
query_memory(query="喜欢") → 返回 ["用户喜欢苹果", "用户喜欢香蕉"]
    ↓
LLM 第 2 次调用: 根据结果生成回复
    ↓
"你之前说过喜欢苹果和香蕉呢~"
```

### 3.3 自动存储（new_memories）

**时机**：每次对话结束时

**代码位置**：`agent/chat/chat_agent.py`

```python
# LLM 返回的 ChatResponse 包含 new_memories
if chat_response.new_memories:
    for mem in chat_response.new_memories:
        self._memory_manager.smart_add_memory(
            content=mem.content,
            memory_type=MemoryType(mem.memory_type)
        )
```

**ChatResponse 结构**（`agent/chat/chat_schema.py`）：
```python
class ChatResponse(BaseSchema):
    text: str                          # 给用户看的回复
    emotion: Emotion                   # 情绪（用于选动画）
    new_memories: list[MemoryExtract]  # LLM 自动提取的新记忆

class MemoryExtract(BaseSchema):
    content: str          # 记忆内容
    memory_type: str      # 记忆类型 ("fact", "preference", ...)
```

**示例**：
```
用户: "我叫小明"
    ↓
LLM 返回:
{
  "text": "好的~小明~",
  "emotion": "happy",
  "new_memories": [
    {"content": "用户叫小明", "memory_type": "fact"}
  ]
}
    ↓
ChatAgent 自动调用: smart_add_memory("用户叫小明", MemoryType.FACT)
```

## 4. 智能更新策略

### smart_add 机制

**核心逻辑**：在添加前检查是否有相似的旧记忆，如果有则替换。

```python
# smart_add 的完整流程

def smart_add_memory(content, memory_type):
    # 1. 搜索同类型的相似记忆
    similar = find_similar(query=content, memory_type=memory_type, n_results=3, min_score=0.5)

    # 2. 对每个相似旧记忆，判断是否应该替换
    for old in similar:
        if old.content == content:
            continue  # 完全相同，跳过
        
        if should_replace(old.content, content, memory_type):
            mark_for_delete(old.id)

    # 3. 删除旧记忆
    if mark_for_delete:
        delete_by_ids(mark_for_delete)

    # 4. 添加新记忆
    add_memory(content, memory_type)
```

### 偏好类型的智能判断

对于 PREFERENCE 类型，使用关键词匹配来判断"方向相同/不同"：

```python
# 提取偏好的 (方向, 核心内容)
def extract_preference(text):
    # 移除修饰词: "其实", "原来", "特别", ...
    # 移除方向词: "喜欢", "讨厌", "爱", ...
    # 返回: (direction, core)

# 示例
extract_preference("用户喜欢吃苹果")
# → ("like", "吃苹果")

extract_preference("用户讨厌吃苹果")
# → ("dislike", "吃苹果")

extract_preference("用户喜欢吃香蕉")
# → ("like", "吃香蕉")
```

**判断规则**：

| 场景 | 旧记忆 | 新记忆 | 核心内容 | 结果 |
|------|--------|--------|----------|------|
| 改方向 | "用户喜欢吃苹果" | "用户讨厌吃苹果" | 相同（吃苹果） | **替换** |
| 换内容 | "用户喜欢吃苹果" | "用户喜欢吃香蕉" | 不同 | **共存** |
| 都改了 | "用户喜欢吃苹果" | "用户讨厌吃香蕉" | 不同 | **共存** |

### 其他类型的处理

对于非 PREFERENCE 类型（FACT, EVENT, CONTEXT, SKILL）：
- 如果相似度 > 0.5 且内容不同 → 替换

```python
# FACT 类型示例
旧: "用户叫小明" (相似度 0.85)
新: "用户叫小红"
→ 替换 ✓

# EVENT 类型示例
旧: "用户上周去北京" (相似度 0.3)
新: "用户上周去上海"
→ 相似度不够，共存
```

## 5. API 使用指南

### 5.1 初始化

```python
from memory import init_memory, get_memory_manager

# 方式 1: 一键初始化
if init_memory():
    print("记忆系统就绪")

# 方式 2: 详细控制
manager = get_memory_manager()
manager.initialize()
```

### 5.2 添加记忆

```python
from memory import get_memory_manager, MemoryType

manager = get_memory_manager()

# 简单添加
manager.add_memory("用户叫小明", MemoryType.FACT)

# 智能添加（推荐，自动替换）
manager.smart_add_memory("用户叫小红", MemoryType.FACT)

# 带元数据
manager.add_memory(
    "用户喜欢Python",
    MemoryType.PREFERENCE,
    metadata={"source": "llm_extract", "confidence": 0.9}
)
```

### 5.3 检索记忆

```python
# 语义搜索
results = manager.search("我叫什么", n_results=3, min_score=0.4)
for r in results:
    print(f"{r['content']} (相似度: {r['similarity']:.2%})")

# 格式化为 LLM 可读
memory_text = manager.get_relevant_memories("我叫什么", max_items=1)
# "- [fact] (置信度 87%) 用户叫小明"

# 全量获取
all_mem = manager.get_all_memories()

# 按类型过滤
facts = manager.get_all_memories(memory_type=MemoryType.FACT)
```

### 5.4 删除记忆

```python
# 按 ID 删除
manager.delete_by_ids(["memory_id_1", "memory_id_2"])

# 清空全部（不可恢复！）
manager.clear_all()
```

### 5.5 统计

stats = manager.get_memory_stats()

#     "fact": 15,

### 5.6 完整示例

```python
from memory import init_memory, get_memory_manager, MemoryType

# 1. 初始化
if not init_memory():
    raise RuntimeError("记忆系统初始化失败")

manager = get_memory_manager()

# 2. 添加一些记忆
manager.smart_add_memory("用户叫小明", MemoryType.FACT)
manager.smart_add_memory("用户喜欢吃苹果", MemoryType.PREFERENCE)
manager.smart_add_memory("用户喜欢Python", MemoryType.SKILL)

# 3. 修改（smart_add 会自动替换）
manager.smart_add_memory("用户叫小红", MemoryType.FACT)
# 旧的 "用户叫小明" 被替换

# 4. 检索
results = manager.search("我喜欢吃什么")
# 找到: "用户喜欢吃苹果" (相似度 0.75)

# 5. 给 LLM 用的格式化
memory_text = manager.get_relevant_memories("我叫什么")
print(memory_text)
# "- [fact] (置信度 87%) 用户叫小红"

# 6. 统计
print(manager.get_memory_stats())
# {"total": 3, "by_type": {...}}
```

## 6. 配置与调优

### 6.1 Embedding 模型

| 属性 | 值 |
|------|------|
| 模型 | bge-small-zh-v1.5 |
| 大小 | ~100MB |
| 输出维度 | 512 |
| 语言 | 中文优化 |
| 设备 | CPU |
| 首次加载 | ~2-3秒 |
| 后续加载 | <0.5秒 |

### 6.2 相似度阈值

| 场景 | 阈值 | 说明 |
|------|------|------|
| smart_add（替换） | 0.5 | 超过则认为是同一条 |
| MessageBuilder（注入） | 0.3 | 召回更多相关 |
| LLM 工具查询 | 0.3 | 默认查询阈值 |

### 6.3 启动预热

在应用启动时异步预热：

```python
import threading
from memory import get_memory_manager

def warmup_memory():
    manager = get_memory_manager()
    if not manager.is_ready:
        manager.initialize()
        logger.info("[Memory] 预热完成")

# 后台启动
threading.Thread(target=warmup_memory, daemon=True).start()
```

### 6.4 性能指标

| 操作 | 延迟 |
|------|------|
| 首次初始化 | 2-3秒（加载模型） |
| 后续初始化 | <0.5秒 |
| 单次检索 | ~50ms |
| smart_add | ~100ms（检索 + 判断 + 添加） |
| 存储规模 | 1GB ≈ 100万条 |

### 6.5 存储位置

默认存储路径：`{项目根目录}/data/memory/`

```python
# 自定义路径

```
