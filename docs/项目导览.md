## 项目一句话介绍

暖宝是一个 macOS/Windows 桌面宠物，基于 PyQt6 + LangGraph，能陪你聊天、记住你说过的事、查天气、查位置。核心架构：**Qt 事件循环 + 事件总线 + LangGraph 工作流**。

### 2.2 AI Agent 层（按调用链读）

这是项目的智能核心，使用 LangGraph 实现 ReAct 模式。**严格按以下顺序读**：

#### 2.2.1 入口

**[agent/chat/chat_agent.py](file:///Users/yangchengwei/Documents/workspace/github_workspace/my_baby/warming_baby/agent/chat/chat_agent.py)**（485 行，20 分钟）

对外接口，接收用户消息并返回响应。关键：

- `chat()`：处理用户输入，先检查 API Key，再调用 ChatGraph（搜索 `async def chat`）
- `auto_speak()`：宠物主动说话，同样先检查 API Key
- API Key 未配置时直接返回提示，不调 LLM

#### 2.2.2 状态定义

**[agent/chat/state.py](file:///Users/yangchengwei/Documents/workspace/github_workspace/my_baby/warming_baby/agent/chat/state.py)**（45 行，3 分钟）

LangGraph 的 State，所有数据流转通过 State。字段：

- `messages`：对话历史（reducer: add_messages）
- `iteration` / `max_iterations`：循环控制
- `final_response`：最终结果

#### 2.2.3 图编排

**[agent/chat/graph.py](file:///Users/yangchengwei/Documents/workspace/github_workspace/my_baby/warming_baby/agent/chat/graph.py)**（217 行，10 分钟）

LangGraph 图组装，定义 ReAct 循环：

```
START → agent_node → [有 tool_calls?] → tools_node → agent_node (循环)
                   → [无 tool_calls?] → format_node → memory_node → END
```

#### 2.2.4 节点逻辑

**[agent/chat/nodes.py](file:///Users/yangchengwei/Documents/workspace/github_workspace/my_baby/warming_baby/agent/chat/nodes.py)**（513 行，20 分钟）

四个节点的具体实现：

- `agent_node`：调用 LLM 决策（说话还是调工具）
- `CustomToolNode`：执行工具（仅查询类，记忆存储走 memory_node）
- `format_node`：从 HumanMessage 提取记忆，生成 ChatResponse
- `memory_node`：确定性存储用户记忆
- `route_tools`：条件边，判断是否继续循环

## 完整数据流

理解这个流程，就理解了整个项目：

```
用户点击宠物
    │
    ▼
pet/pet.py: show_chat_ui() → 显示输入框
    │
    ▼ (用户输入并发送)
pet/pet.py: 发 USER_MESSAGE 事件
    │
    ▼
agent/chat/chat_agent.py: chat() 接收
    │
    ▼ (检查 API Key)
agent/chat/graph.py: 编排 LangGraph
    │
    ├─→ nodes.py: agent_node (调 LLM 决策)
    │       │
    │       ├─→ [需工具] → CustomToolNode (查天气/位置) → 回 agent_node
    │       └─→ [无需工具] → format_node (生成响应+提取记忆)
    │                              │
    │                              ▼
    │                    memory_node (存储记忆)
    │                              │
    ▼                              ▼
pet/pet.py: 收 RESPONSE 事件
    │
    ├─→ 显示对话气泡
    └─→ 播放对应情绪动画
```

## 关键设计决策

| 问题         | 方案                        | 原因                                 |
| ------------ | --------------------------- | ------------------------------------ |
| 模块解耦     | 事件总线                    | UI 和 Agent 不直接调用，便于独立演进 |
| AI 工作流    | LangGraph ReAct             | 支持 LLM 自主调用工具，循环决策      |
| 记忆存储     | ChromaDB + BGE              | 本地向量数据库，语义检索             |
| 记忆去重     | 归一化 + 跨类型搜索         | 解决 PREFERENCE/FACT 类型判断不稳定  |
| API Key 存储 | 本地 JSON                   | 避免 macOS 钥匙串弹窗                |
| 单例保护     | fcntl 文件锁                | 不依赖 Qt，最可靠                    |
| Embedding    | 自定义 BGEEmbeddingFunction | 绕过 sentence_transformers 打包问题  |
| 退出         | os.\_exit(0)                | 不依赖 Qt 事件循环，避免"复活"       |
