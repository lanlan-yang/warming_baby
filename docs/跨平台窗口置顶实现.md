# 跨平台 PyQt6 窗口置顶实现

## 问题背景

在 PyQt6 中实现窗口置顶功能在不同平台有不同的方案：

| 平台 | Qt 默认方案 | 问题 | 原生方案 |
|------|------------|------|----------|
| **macOS** | `WindowStaysOnTopHint` | 被转为 `NSFloatingWindowLevel`，不是最高层 | AppKit (pyobjc) |
| **Windows** | `WindowStaysOnTopHint` | 可用但会抢焦点 | Win32 API (SetWindowPos) |

本项目提供了统一的跨平台封装 `core/topmost.py`，自动根据系统选择实现。

## 核心方案

### 架构设计

```
┌─────────────────────────────────────────────────────────┐
│                  core/topmost.py                          │
├─────────────────────────────────────────────────────────┤
│                                                           │
│  set_window_topmost(window)  ← 统一入口                   │
│           │                                               │
│           ├── sys.platform == 'darwin'                    │
│           │     └── _set_topmost_macos()                  │
│           │           └── AppKit.NSStatusWindowLevel      │
│           │                                               │
│           └── sys.platform == 'win32'                     │
│                 └── _set_topmost_windows()                 │
│                       └── SetWindowPos(HWND_TOPMOST)       │
│                                                           │
└─────────────────────────────────────────────────────────┘
```

### 使用方式

```python
from core.topmost import set_window_topmost

class MyWindow(QWidget):
    def showEvent(self, event):
        super().showEvent(event)
        # 延迟调用确保窗口已创建
        QTimer.singleShot(10, self._apply_topmost)
        QTimer.singleShot(100, self._apply_topmost)
        QTimer.singleShot(500, self._apply_topmost)
    
    def _apply_topmost(self):
        set_window_topmost(self)
```

## macOS 实现详情

### 失败的尝试

| 方案 | 问题 |
|------|------|
| `WindowStaysOnTopHint` | 转为 `NSFloatingWindowLevel`，不是最高层 |
| `WindowStaysOnTopHint \| Tool` | Tool 创建 NSPanel，有独立窗口管理 |
| 修改 `styleMask` | 破坏 Qt 事件处理 |

### 正确做法

```python
import objc
from AppKit import (
    NSStatusWindowLevel,  # 最高层（与菜单栏同级）
    NSWindowCollectionBehaviorCanJoinAllSpaces,
    NSWindowCollectionBehaviorStationary,
)

win_id = int(self.winId())
ns_view = objc.objc_object(c_void_p=win_id)
ns_window = ns_view.window()

# 关键设置（顺序重要）
ns_window.setLevel_(NSStatusWindowLevel)
ns_window.setCollectionBehavior_(
    NSWindowCollectionBehaviorCanJoinAllSpaces |
    NSWindowCollectionBehaviorStationary
)
ns_window.orderFrontRegardless()  # 置顶但不激活
```

### AppKit 常量

| 常量 | 值 | 说明 |
|------|-----|------|
| `NSStatusWindowLevel` | 25 | 最高层（与菜单栏同级） |
| `NSFloatingWindowLevel` | 3 | 浮动层（不够高） |
| `NSNormalWindowLevel` | 0 | 普通层 |

### 最佳实践

1. **多次调用**：macOS 窗口创建是异步的，建议 `10ms + 100ms + 500ms` 调用三次
2. **定时刷新**：每 200-500ms 刷新一次防止被系统重置
3. **不要修改 styleMask**：保持 Qt 设置的样式

## Windows 实现详情

### Win32 API

```python
import ctypes
from ctypes import wintypes

HWND_TOPMOST = -1
SWP_NOSIZE = 0x0001
SWP_NOMOVE = 0x0002
SWP_NOACTIVATE = 0x0010

win_id = int(self.winId())
hwnd = wintypes.HWND(win_id)

ctypes.windll.user32.SetWindowPos(
    hwnd,
    HWND_TOPMOST,
    0, 0, 0, 0,
    SWP_NOSIZE | SWP_NOMOVE | SWP_NOACTIVATE  # 关键：不抢焦点
)
```

### SetWindowPos 参数

| 参数 | 说明 |
|------|------|
| `HWND_TOPMOST` | 置于所有窗口之上 |
| `SWP_NOSIZE` | 不改变窗口大小 |
| `SWP_NOMOVE` | 不改变窗口位置 |
| `SWP_NOACTIVATE` | **不激活窗口**（防止抢焦点） |

### 注意事项

1. **窗口句柄**：确保在 `showEvent` 之后调用，`winId()` 才返回有效值
2. **DPI 缩放**：Win32 API 不自动处理 DPI，必要时调用 `SetProcessDpiAwareness`
3. **定时刷新**：Windows 在某些操作（如最大化/还原）后会重置 Z-order

## 项目实际应用

### 窗口属性设置

```python
class NuanbaoPet(QWidget):
    def __init__(self):
        super().__init__()
        
        # Qt 属性（注意：不使用 WindowStaysOnTopHint）
        self.setWindowFlags(Qt.WindowType.FramelessWindowHint)
        self.setAttribute(Qt.WidgetAttribute.WA_TranslucentBackground)
        self.setAttribute(Qt.WidgetAttribute.WA_ShowWithoutActivating)
        self.setAttribute(Qt.WidgetAttribute.WA_NoSystemBackground)
```

### showEvent 中的调用

```python
def showEvent(self, event):
    super().showEvent(event)
    # 跨平台置顶
    QTimer.singleShot(10, self._apply_topmost_native)
    QTimer.singleShot(100, self._apply_topmost_native)
    QTimer.singleShot(500, self._apply_topmost_native)

def _apply_topmost_native(self):
    if set_window_topmost(self):
        # 定时刷新
        if not hasattr(self, '_topmost_timer'):
            self._topmost_timer = QTimer(self)
            self._topmost_timer.timeout.connect(
                lambda: set_window_topmost(self)
            )
            self._topmost_timer.start(200)
```

## 对比总结

| 特性 | macOS (AppKit) | Windows (Win32) |
|------|---------------|-----------------|
| API 类型 | Objective-C 桥接 (pyobjc) | C API (ctypes) |
| 最高层级 | `NSStatusWindowLevel` (25) | `HWND_TOPMOST` (-1) |
| 跨 Space | 支持 | 不适用 |
| 不抢焦点 | `orderFrontRegardless` | `SWP_NOACTIVATE` |
| 需要定时刷新 | ✅ (系统会重置) | ✅ (Z-order 变化) |
| 依赖 | pyobjc-framework-Cocoa | 无（ctypes 内置） |
