# 桌面宠物约束文档

## 1. 技术栈

- **框架**: PyQt6
- **Python版本**: 3.13+
- **枚举**: 使用 `enum.StrEnum` (标准库)
- **配置**: pydantic-settings
- **日志**: loguru

## 3. 枚举规范

### 所有枚举集中在 core/enums.py

```python
from enum import StrEnum

class AnimationType(StrEnum):
    """动画类型"""
    WALK = 'walk'
    STAND = 'stand'
    FLY = 'fly'
    TOUCH = 'touch'

class PetState(StrEnum):
    """宠物状态"""
    WALKING = 'walking'
    IDLE = 'idle'
    FLYING = 'flying'
    TOUCHED = 'touched'
    HOVERING = 'hovering'
```

### 导入方式

```python
from core import AnimationType, PetState
```

## 4. 事件系统

### 4.1 UI -> AI (PetSignals)

```python
pet.signals.on_click          # 用户点击
pet.signals.on_drag_start     # 开始拖拽
pet.signals.on_drag_end       # 结束拖拽
pet.signals.on_hover_enter    # 鼠标悬停进入
pet.signals.on_hover_leave    # 鼠标悬停离开
pet.signals.on_animation_end  # 动画结束 (anim_name: str)
```

### 4.2 AI -> UI (trigger_animation)

```python
# 持续播放
pet.trigger_animation('walk')

# 播放一次后回到之前状态
pet.trigger_animation('happy', play_once=True)
```

### 4.3 动画名称映射

| 名称 | 枚举 | 说明 |
|------|------|------|
| walk | AnimationType.WALK | 走路 |
| stand / idle | AnimationType.STAND | 站立/待机 |
| fly | AnimationType.FLY | 飞行 |
| touch | AnimationType.TOUCH | 触摸 |
| happy | AnimationType.TOUCH | 快乐(映射touch) |

## 5. 动画资源规范

### 5.1 文件命名

- 小写下划线: `walk_left.gif`, `stand_by.gif`
- 统一放在 `images/action/` 目录

### 5.2 新增动画步骤

1. 将 GIF 放入 `images/action/`
2. 在 `core/enums.py` 的 `AnimationType` 添加枚举值
3. 在 `pet/pet.py` 的 `__init__` 中加载
4. 在 `_on_play_from_external` 的 `anim_map` 添加映射

## 6. UI规范

### 6.1 窗口属性

- 无边框: `FramelessWindowHint`
- 置顶: `WindowStaysOnTopHint`
- 工具窗口: `Tool` (不显示在任务栏)
- 透明背景: `WA_TranslucentBackground`

### 6.2 交互规则

- 鼠标悬停: 切换 `stand` 动画 + 手型光标
- 鼠标离开: 切换 `walk` 动画
- 点击(不移动): 播放 `touch` 动画
- 拖拽(移动>5px): 播放 `fly` 动画
- 右键: 弹出菜单

### 6.3 方向控制

- `facing_right = True`: 正常显示
- `facing_right = False`: `scale(-1, 1)` 水平翻转
- 拖拽时根据鼠标移动方向自动切换

## 7. 代码规范

- 所有字符串比较用枚举，不用硬编码
- 路径用 `os.path.dirname(os.path.abspath(__file__))` 获取相对路径
- 动画切换先停止旧动画，再启动新动画
- 信号断开用 try-except 包裹，避免未连接时报错
