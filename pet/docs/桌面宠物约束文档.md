# 桌面宠物约束文档

## 1. 技术栈

- **框架**: PyQt6
- **Python版本**: 3.13+
- **枚举**: 使用 `enum.StrEnum` (标准库)
- **配置**: pydantic-settings
- **日志**: loguru
- **事件通信**: EventBus (自定义发布-订阅模式)

## 4. 事件系统 (EventBus)

### 4.1 4种事件分类

| 分类   | 枚举        | 用途                                |
| ------ | ----------- | ----------------------------------- |
| System | SystemEvent | 系统级事件 (启动、关闭、错误)       |
| UI     | UIEvent     | 用户界面事件 (点击、拖拽、悬停)     |
| Agent  | AgentEvent  | AI Agent事件 (思考、响应、工具调用) |
| Pet    | PetEvent    | 宠物行为事件 (动画、状态、移动)     |

### 4.2 事件列表

#### SystemEvent - 系统事件

```python
SystemEvent.STARTUP       # 应用启动
SystemEvent.SHUTDOWN      # 应用关闭
SystemEvent.ERROR         # 系统错误
SystemEvent.CONFIG_CHANGED  # 配置变更
```

#### UIEvent - 用户界面事件

```python
UIEvent.MOUSE_CLICK       # 鼠标点击 (参数: x, y)
UIEvent.MOUSE_DOUBLE_CLICK # 鼠标双击
UIEvent.MOUSE_DRAG_START  # 开始拖拽
UIEvent.MOUSE_DRAG_END    # 结束拖拽
UIEvent.MOUSE_DRAG_MOVE   # 拖拽移动 (参数: x, y)
UIEvent.MOUSE_HOVER_ENTER # 悬停进入
UIEvent.MOUSE_HOVER_LEAVE # 悬停离开
UIEvent.KEY_PRESS         # 键盘按键
UIEvent.WINDOW_MOVE       # 窗口移动
UIEvent.WINDOW_RESIZE     # 窗口大小改变
```

#### AgentEvent - AI事件

```python
AgentEvent.THINKING         # AI开始思考
AgentEvent.RESPONSE         # AI响应 (参数: response={emotion, ...})
AgentEvent.RESPONSE_STREAM  # AI流式响应
AgentEvent.TOOL_CALL        # AI调用工具
AgentEvent.TOOL_RESULT      # 工具返回结果
AgentEvent.ERROR            # AI错误
```

#### PetEvent - 宠物事件

```python
PetEvent.ANIMATION_START    # 动画开始 (参数: anim_name)
PetEvent.ANIMATION_END      # 动画结束 (参数: anim_name)
PetEvent.ANIMATION_CHANGED  # 动画切换 (参数: from_, to)
PetEvent.STATE_CHANGED      # 状态变更
PetEvent.MOVE               # 位置移动
PetEvent.DIRECTION_CHANGED  # 朝向变更 (参数: facing_right)
```

### 4.3 使用方式

```python
from core import event_bus, EventCategory, UIEvent, PetEvent, AgentEvent

# 订阅事件
def on_click(x, y):
    print(f"点击位置: {x}, {y}")
event_bus.subscribe(EventCategory.UI, UIEvent.MOUSE_CLICK, on_click)

# 发布事件
event_bus.publish(EventCategory.UI, UIEvent.MOUSE_CLICK, x=100, y=200)

# AI触发宠物动画
event_bus.publish(EventCategory.AGENT, AgentEvent.RESPONSE,
                 response={'emotion': 'happy', 'play_once': True})

# 取消订阅
event_bus.unsubscribe(EventCategory.UI, UIEvent.MOUSE_CLICK, on_click)
```

## 5. 宠物行为规范

### 5.1 动画映射表

| 外部名称     | 对应枚举            | 说明               |
| ------------ | ------------------- | ------------------ |
| walk         | AnimationType.WALK  | 走路               |
| stand / idle | AnimationType.STAND | 站立/待机          |
| fly          | AnimationType.FLY   | 飞行               |
| touch        | AnimationType.TOUCH | 触摸               |
| happy        | AnimationType.TOUCH | 快乐 (映射到touch) |

### 5.2 触发动画

```python
# 方式1: 直接调用 (AI代码可用)
pet.trigger_animation('happy', play_once=True)

# 方式2: 通过事件总线 (推荐)
event_bus.publish(EventCategory.AGENT, AgentEvent.RESPONSE,
                 response={'emotion': 'happy', 'play_once': True})
```

### 5.3 宠物交互行为

| 用户操作     | 触发条件           | 宠物行为                   | 发布事件                               |
| ------------ | ------------------ | -------------------------- | -------------------------------------- |
| **鼠标按下** | 左键               | 记录起始位置               | -                                      |
| **鼠标移动** | 左键按下且移动>5px | 播放fly, 开始拖拽          | `MOUSE_DRAG_START`                     |
| **鼠标移动** | 拖拽中             | 跟随鼠标移动, 根据方向翻转 | `MOUSE_DRAG_MOVE`, `DIRECTION_CHANGED` |
| **鼠标释放** | 拖拽结束           | 根据悬停状态播放stand/walk | `MOUSE_DRAG_END`                       |
| **鼠标释放** | 未拖拽 (点击)      | 播放touch (4.3秒)          | `MOUSE_CLICK`                          |
| **鼠标悬停** | 进入宠物区域       | 播放stand, 显示手型光标    | `MOUSE_HOVER_ENTER`                    |
| **鼠标离开** | 离开宠物区域       | 播放walk, 恢复默认光标     | `MOUSE_HOVER_LEAVE`                    |
| **右键点击** | -                  | 显示菜单 (退出)            | -                                      |

### 5.4 自动移动行为

| 条件                            | 行为                                |
| ------------------------------- | ----------------------------------- |
| 未悬停、未拖拽、未播放touch/fly | 自动移动                            |
| 随机改变水平方向                | 概率 0.5%                           |
| 随机改变垂直方向                | 概率 0.3%                           |
| 碰到屏幕边缘                    | 反向移动                            |
| 移动方向改变                    | 翻转朝向 (发布 `DIRECTION_CHANGED`) |

### 5.5 Touch动画特殊规则

- 点击后播放touch动画
- 固定4.3秒后结束
- 结束后判断: 悬停→stand, 未悬停→walk
- 重复点击时检查是否已在播放, 避免重复触发

## 6. 动画资源规范

### 6.1 文件命名

- 小写下划线: `walk_left.gif`, `stand_by.gif`
- 统一放在 `images/action/` 目录
- 建议帧率: 10-15 FPS
- 建议尺寸: 适配 display_height=120

### 6.2 新增动画步骤

1. 将 GIF 放入 `images/action/`
2. 在 `core/enums.py` 的 `AnimationType` 添加枚举值
3. 在 `core/event_bus.py` 的事件枚举添加新事件 (如需要)
4. 在 `pet/pet.py` 的 `__init__` 中加载动画
5. 在 `pet/pet.py` 的 `trigger_animation` 的 `anim_map` 添加映射
6. 更新本文档

## 7. UI规范

### 7.1 窗口属性

- 无边框: `FramelessWindowHint`
- 置顶: `WindowStaysOnTopHint`
- 工具窗口: `Tool` (不显示在任务栏)
- 透明背景: `WA_TranslucentBackground`

### 7.2 方向控制

- `facing_right = True`: 正常显示
- `facing_right = False`: `QTransform().scale(-1, 1)` 水平翻转
- 拖拽时根据鼠标移动方向自动切换
- 自动移动时根据方向自动切换

### 7.3 性能优化

- 仅在尺寸变化时调用 `resize()`
- 帧更新使用 `SmoothTransformation` 缩放

## 8. 代码规范

### 8.1 导入规范

```python
# 推荐: 从core统一导入
from core import (
    AnimationType, PetState,
    event_bus, EventCategory,
    UIEvent, PetEvent, AgentEvent, SystemEvent
)

# 不推荐: 直接导入内部模块
from core.enums import AnimationType  # ❌
```

### 8.2 路径规范

```python
# 正确: 使用 __file__ 获取相对路径
base_dir = os.path.dirname(os.path.abspath(__file__))
anim_path = os.path.join(base_dir, 'images', 'action', 'walk.gif')

# 错误: 使用绝对路径或当前工作目录
anim_path = '/home/user/project/images/action/walk.gif'  # ❌
anim_path = 'images/action/walk.gif'  # ❌ (依赖运行目录)
```

### 8.3 事件规范

```python
# 正确: 使用枚举
event_bus.publish(EventCategory.UI, UIEvent.MOUSE_CLICK, x=100)
event_bus.publish(EventCategory.PET, PetEvent.ANIMATION_START, 'walk')

# 错误: 使用字符串
event_bus.publish('ui', 'click')  # ❌
```

### 8.4 异常处理

```python
# 信号断开必须用 try-except
try:
    self.movie.frameChanged.disconnect(self.on_frame)
except (TypeError, RuntimeError):
    pass
```

### 8.5 动画切换

```python
# 正确: 先停止旧动画, 再启动新动画
def play(self, anim_type):
    if self.current_movie:
        self.current_movie.stop()
        # 断开连接...

    self.current_movie = new_movie
    new_movie.start()

# 错误: 不停止旧动画直接切换
def play(self, anim_type):
    new_movie.start()  # ❌
```
